# Правила проекта

- Все комментарии, сообщения коммитов, документация и тексты интерфейса — на русском языке.
- Рабочее имя продукта — LUMIÈRE Broadcast, имя репозитория — broadcast-studio.
- Не заменять CasparCG/MediaMTX имитацией в production. Тестовые адаптеры допускаются только в tests.
- При изменении управляющих команд проверять принадлежность источников каналу и revision.
- HLS-манифесты и сегменты проходят одну региональную политику. Не публиковать прямой обход к MediaMTX.
- Не отправлять S3 Secret Key или подписанные URL в браузер. Секреты хранить через IDataProtection.
- Для схемы PostgreSQL создавать миграции EF Core; SQLite — только для разработки и тестов.
- Проверки: dotnet test BroadcastStudio.sln; в src/broadcast-web — npm run lint и npm run build.
- Указывать в docs/verification.md, какие медиапроверки реально выполнены, а какие требуют целевого сервера.
- Не добавлять несколько worker-реплик до реализации распределённого lease.
