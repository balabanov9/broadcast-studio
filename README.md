# LUMIÈRE Broadcast

**Ваш эфир. Под контролем.** Система автоматизации телевизионного вещания: ASP.NET Core 10, PostgreSQL, EF Core, SignalR, Next.js, React, Tailwind CSS, shadcn/ui, CasparCG, MediaMTX и FFmpeg.

> Ранняя версия MVP. Это начало разработки, а не сертифицированная аппаратная для ответственного вещания. Список выполненных проверок и границ реализации находится в [документации](docs/verification.md).

## Возможности первого этапа

- До четырёх независимых телеканалов, у каждого собственные Preview/Program и ключ OBS.
- Настоящие команды AMCP в CasparCG: выбор Preview, CUT и MIX; HLS-мониторы показывают выходы движка.
- Загрузка видео с проверкой FFprobe, цветовые источники, прямой вход OBS через RTMP.
- Редактор графики Full HD: текстовый логотип, титр, бегущая строка и текст субтитров. Перемещение мышью, координаты, размеры, цвета; HTML-шаблон CasparCG с анимацией.
- Циклические плейлисты, блоки расписания, автопилот, возврат к позиции по времени блока, резерв вне расписания и при пропадании OBS.
- Экспорт M3U и XMLTV EPG.
- Ограничения IPTV по странам и регионам: GeoIP, отдельный поток заставки, загрузка собственной PNG/JPEG. Проверка доступа на каждом HLS-манифесте и сегменте.
- Вход оператора, защищённая cookie, проверка Origin, ограничение попыток входа, журнал событий, обновления через SignalR.

## Быстрый запуск

Требуются Linux x86-64, Docker Engine с Compose v2 и OpenSSL. Для графики CasparCG используется OpenGL/CEF; минимальное окружение проверяется на целевом сервере отдельно.

```bash
./scripts/init-env.sh
# Откройте .env: пароль входа — OPERATOR_PASSWORD.
docker compose up --build -d
```

Откройте **http://localhost:8088**, войдите и создайте канал. Выберите резерв в Preview, затем CUT. Загрузите видео или подключите OBS в разделе «IPTV и подключения».

Не публикуйте `.env`. Для внешнего доступа настройте HTTPS, `PUBLIC_ORIGIN`, привязку `HTTP_BIND` и доверенный прокси по [инструкции эксплуатации](docs/operations.md). Порты HLS/API MediaMTX и AMCP наружу не открываются: иначе региональные ограничения можно обойти.

## Региональные ограничения

Разместите собственную лицензионную базу MaxMind `GeoLite2-City.mmdb` в `geoip/` и перезапустите API. База Country подходит для стран; City нужна для областей и регионов. В разделе «IPTV и подключения» укажите запрещённые ISO-коды, например `RU, NL`, и включите ограничения. Для областей используйте коды из вашей GeoIP City.

Стандартная заставка находится в `graphics/region-unavailable.png`. Своё изображение загружается из панели, нормализуется FFmpeg в 1920 × 1080 и выдаётся отдельным HLS-потоком. Основной эфир от этого не меняется. Неизвестный регион по умолчанию получает заставку. Без базы GeoIP включение политики запрещено.

GeoIP определяет расположение IP, а не фактическое местонахождение человека; VPN определяется как адрес выхода VPN. Это не DRM. Не используйте публичный CDN-кеш перед HLS-шлюзом без отдельной схемы авторизации сегментов.
